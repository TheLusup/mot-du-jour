Comment jouer

Un mot par jour, le même pour tout le groupe. La première lettre est donnée, tu as 6 essais. Chaque essai doit être un mot français qui commence par cette lettre.

C
H
A
T
S

Bleu : bonne lettre, bien placée.
Rond orange : la lettre est dans le mot, mais ailleurs.
Gris : la lettre n'est pas (ou plus) dans le mot.

Pas d'accents à taper : É = E. Nouveau mot chaque jour à minuit (heure de Paris).
